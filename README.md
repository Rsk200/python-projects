## 🌟 About This Repository

Welcome to my Python learning journey! This repository contains a collection of Python projects that I've built while learning how to code. 

If you are a beginner looking for inspiration, feel free to explore the code. Each project is designed to tackle specific programming concepts like loops, functions, error handling, and clean code architecture.

---

## 🚀 Projects Included

### 1. [🧮 Simple Calculator](./Simple%20Calculator/)
A robust, interactive command-line calculator.
- **Concepts Learned:** `while` loops, `try/except` error handling, lambda functions, file I/O (saving history), and modern `match/case` statements.
- **Highlights:** Prevents crashes from bad user input and saves your calculation history to a text file!

### 2. [🎯 Number Guessing Game](./Number%20Guessing/)
A fun, interactive game where you try to guess a secret number.
- **Concepts Learned:** `random` module, conditional logic (`if/elif/else`), user input parsing, and loop control statements (`break`/`continue`).

## 💻 How to Use

To run any of these projects locally on your computer:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Rsk200/python-projects.git
   ```
2. **Navigate into the project folder:**
   ```bash
   cd python-projects/"Simple Calculator"
   ```
3. **Run the Python file:**
   ```bash
   python calculator.py
   ```

*(Make sure you have [Python](https://www.python.org/downloads/) installed on your machine!)*
