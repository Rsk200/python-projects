# 🌡️ Universal Temperature Converter

## Description
A robust Python application built to convert temperatures across multiple scales (Celsius, Fahrenheit, Kelvin, and Rankine). This project emphasizes defensive programming against bad user input and teaches how to manipulate complex data structures.

## Features
- Convert between major temperature scales.
- Fully protected against crashes using `try/except` for user inputs.
- Continuous loop using an interactive text menu.
- A sophisticated `history.txt` logging system built using lists of dictionaries and Python File I/O.
- Extremely clean mathematics using Python's `lambda` expressions and `match/case` routing.

## How to use
1. Make sure Python 3.10+ is installed.
2. Navigate into the `Temperature Converter` folder.
3. Run the application:
   ```bash
   python converter.py
   ```
4. Follow the on-screen menu. View your past conversions by pressing `5`.
