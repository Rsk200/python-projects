## 🌟 Overview

The **Python Terminal Calculator** is a command-line application that demonstrates fundamental and intermediate Python programming concepts. Built as part of a beginner-to-advanced learning journey, it focuses heavily on clean architecture, modularity, and bulletproof user input validation.

## ✨ Key Features

- **Standard Arithmetic**: Addition, Subtraction, Multiplication, Division.
- **Interactive Interface**: A continuous `while True` loop that keeps the application alive.
- **Graceful Error Handling**: Complete protection against invalid text inputs (`ValueError`) using robust `try/except` blocks.
- **Mathematical Safety**: Built-in safeguards against `ZeroDivisionError`.
- **Modern Syntax**: Utilizes Python 3.10+ `match/case` structural pattern matching for clean control flow.
- **Beautiful Output**: Utilizes Python `f-strings` for perfectly formatted console messages.

## 🚀 Getting Started

### Prerequisites
Make sure you have Python installed on your system (Python 3.10 or higher is recommended for the `match/case` syntax).

### Installation & Execution

1. Navigate to the `Simple Calculator` directory.
2. Run the application from your terminal:

```bash
python calculator.py
```

3. Follow the on-screen interactive menu to perform your calculations!

## 🏗️ Architecture & Learnings

This project practically applies the following core computer science and Python concepts:

* **Modular Design**: Breaking down operations into isolated functions (`def add()`, `def subtract()`, etc.).
* **Return Values vs Side Effects**: Emphasizing the use of the `return` statement over direct printing for reusable logic.
* **Flow Control**: Managing application state with loops (`while`, `break`, `continue`) and conditional logic.
